# HR-Workforce-Attrition-Analysis
Overall attrition rate stood at 50.7% across 3,400 employees — high, but uninformative on its own. It tells us something is wrong, not where
Cause:
Tested single factors individually (department, job role, income, tenure, overtime) — none showed a strong standalone relationship. Cross-tabulating Overtime × Job Satisfaction revealed the real driver: employees with low job satisfaction and no overtime showed a 12-point higher attrition gap — more than double the effect visible when overtime was analyzed alone.
Decision:
Instead of broad company-wide retention programs, effort should concentrate on the low-satisfaction / no-overtime segment specifically — a much smaller, higher-leverage target.
Recommended Action:
Targeted exit interviews for this segment; stronger data-validation rules to fix 640 records (18.8%) with inconsistent tenure data before future analysis.
Result/Value:
Not applicable — this is a training project using a public dataset, not an implemented company initiative. No real "before/after" exists to report honestly.
